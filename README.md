# Agency landing

Storyboards and mockups for the landing page of an AI-native commerce agency for fashion, beauty and jewelry brands.

## Structure

| Folder | What goes there |
|---|---|
| `storyboard/desktop/` | Desktop storyboard frames (1440 px) and the storyboard document |
| `mockups/` | HTML mockups the frames are screenshotted from |
| `assets/products/` | Real product photos (JPG, 1600 px or larger on the long side) |
| `assets/team/` | Team photos |

Desktop first, then mobile.
